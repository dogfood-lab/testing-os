# rust-landings

An Atlas fixture for what a Rust program writes and reads, the shapes
saints-mile and glyphstudio have. The ledger binary writes a report by a
relative path, reads a table beside its manifest through
env!("CARGO_MANIFEST_DIR"), and writes to places its caller decides: a
directory clap parses from the command line, the home directory, the
working directory, an environment variable and a directory a function is
handed. One path is built at run time. A unit test writes a scratch file
the map leaves out. A nightly workflow runs the binary and commits the
report.
