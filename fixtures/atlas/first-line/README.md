# first-line

An Atlas fixture for what the first line says a repository is, the shape
site-theme has: Astro components and a stylesheet the package ships, a CLI
in JavaScript, a shell script, and a workflow that deploys the handbook to
GitHub Pages; beside them, a directory of eleven Markdown notes and a much
larger one of JSON records. The line counts the Astro, CSS and shell files
as code it does not parse, names the Markdown beside the JSON it is
mostly, and says the repository deploys a site.
