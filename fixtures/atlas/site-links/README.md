# site-links

An Atlas fixture for a site configuration whose calls to action link to
pages, the shapes schumann-surface and sovereign have:
`primaryCta: { href: 'viewer/' }` and
`{ href: 'release/solo.html' }`. Each is a link on the site's own URL,
never a read of the tracked `viewer/` or `release/` it happens to share a
name with.
