# cwd-output

An Atlas fixture for output a script writes under the directory it is run
from, and that the repository commits, the shape multi-claude's stop drill
has: test/drill/stop-drill.ts writes .multi-claude/drill/ under
process.cwd(), each file by name but its logs, whose names it builds at run
time; every file it wrote there is tracked. scripts/scratch.mjs writes under
process.cwd() too, to a place nothing tracks.
