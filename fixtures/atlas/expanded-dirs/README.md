# expanded-dirs

An Atlas fixture for working directories spelled with an expression. CI
tests each package of a matrix in `packages/${{ matrix.project }}`, the
shape accessibility-suite has; a dispatch publishes the wrapper its input
names from `examples/${{ inputs.tool }}`, the shape npm-launcher has. None
of these manifests is a workspace. Each directory the expression can be is
worked in, each wrapper is published by name, and the commands of each
manifest are doors; beta is private, so its command is one nothing ships.
