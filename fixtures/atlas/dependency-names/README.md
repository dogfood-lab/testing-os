# dependency-names

An Atlas fixture for Python dependencies imported under a name their
distribution does not fold to, beside local modules of that name, the
shapes sovereignty and audiobooker have: xrpl-py is imported as xrpl and
python-docx as docx, while app/wallet/xrpl.py and app/parser/docx.py are
local modules no import path from app/ledger.py reaches. Both imports are
the dependencies.
